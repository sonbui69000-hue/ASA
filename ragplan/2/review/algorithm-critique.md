# Algorithm selection challenge

Date: 2026-11-16. No new extraction/retrieval/model benchmark results are claimed. The existing plan already proposes credible ablations; the problem is not that every advanced arm must run before coding. The baseline should remain provisional until its own task, security and resource gates pass.

Every row answers eight questions: **A** assumption; **E** supporting evidence; **S** whether it solves the problem; **B** better-established alternative; **C** CPU/memory/latency/maintenance cost; **Q** simpler quality improvement; **R** later rework; **X** decisive experiment. “Evidence” distinguishes mechanism documentation from local VI/EN results. Findings referenced here are defined in [the master review](hostile-review.md); experiment AX identifiers specify tests, not additional confirmed defects.

Cost notation is qualitative, not a benchmark: deterministic = bounded code/SQL, no new model; native = page-bounded parser; OCR/layout = separate limited worker; encoder = token-dependent inference; pairwise = candidate-count × pair inference; generative = new serving/runtime/model lifecycle. The proposed 8-vCPU/32-GiB envelope is unmeasured. Memory includes process/runtime/batches and subprocesses, not just weights. All approaches must remain local and authorized; none may route to external AI or the imported workbook workspace.

The table graph should preserve containment through cell elements, omitted positions and distinct header observations; no evidence supports flattening it. [python-docx table semantics](https://python-docx.readthedocs.io/en/latest/user/tables.html) explain why repeated merged-cell text is not independent evidence. PDF coordinates and DOCX part locators are expensive-to-reverse foundations; confidence thresholds and specific parser adapters are replaceable.

Recommendation: retain native/OOXML + selective local OCR/layout, evidence-preserving chunks, explicit lexical/exact paths and a measured E5 hybrid candidate. Reconsider defaults through the existing E01–E09 experiments with the added cases above. Prioritize legal/corpus/semantic identities and executable query/budget contracts over new rerankers, sparse models, generated context or VLMs.
